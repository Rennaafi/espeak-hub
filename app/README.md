# ESPeak Hub app

Flutter (Android) client: hold-to-talk, chat history (sqflite), phone/speaker switch, EN / Buddy / Korean modes, Dess's face.

Copy `env.json.example` to `env.json`, fill in your Worker URL and app key, then:

    flutter run --dart-define-from-file=env.json

See the top-level README for the whole system.
